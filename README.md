# Claude-Industrial-Sound-Maker

工业声音生成器 · Play with some industrial core sound.

一个纯前端页面，用 Web Audio API 实时合成工业声音，不依赖任何采样文件，并带一个像素风的机器动画（会喷气、转齿轮、冒火花）。

## 运行

直接用浏览器打开 `index.html`，或者起一个静态服务器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

首次需要点击「启动机器」以解锁浏览器音频。

## 声音

| 键 | 名称 | 合成方式 |
|----|------|----------|
| 1 | 敲石头 Stone Hit | 带通噪声裂响 + 低频敲击 + 碎屑颗粒 |
| 2 | 敲管道 Pipe Hit | 自由梁模态分音（1 : 2.76 : 5.40 : 8.93）微失谐拍频 + 空腔共鸣 + 撞击噪声 |
| 3 | 机器撞击 Machine Impact | 次低音下潜 + 失真金属分音 + 噪声砸击 + 余震碎响 |
| 4 | 敲铃铛 Bell | 10 个非谐波分音，各自独立衰减（hum 最长） |
| 5 | 敲镲 Cymbal | 808 风格 6 路方波 + 噪声，削波后高通，双包络（亮边 + 余音） |
| 6 | 牛铃 Cowbell | 808 风格 587 / 845 Hz 方波，带通 + 快衰减 |
| 7 | 机器喷气 Steam Vent | 阀门爆音 + 频率扫掠的嘶声，同时触发像素蒸汽动画 |
| 8 | 机器转动 Machine Rotation（循环） | 锯齿波马达 + LFO 调制皮带呼啸 + 齿轮研磨 + 节奏性叮当，可调转速 |
| 9 | 沉闷的机器声 Dull Machine Drone（循环） | 50 / 100 / 150 Hz 电流嗡鸣 + 27.5 Hz 隆隆 + 低通噪声底 + 周期性闷响与随机撞击，可调沉闷程度 |

每次敲击都带有轻微随机变化。所有声音经过一个共享的「车间混响」（生成式脉冲响应卷积）和压缩器总线。

## 功能

- **敲击板**：点击或按键盘 1–7 触发。
- **机器**：按 8 / 9 切换转动与沉闷机器声，滑块实时调节参数。
- **像素动画**：画面本身可点击——喷气口喷气、铃铛 / 牛铃 / 镲摆动、石头敲击扬尘、机器体撞击震屏冒火花、齿轮随「机器转动」旋转、指示灯随沉闷机器声呼吸。
- **音序器**：16 步 × 7 音色，BPM 50–220，自带一段 industrial 预设节奏，支持随机与清空。空格键播放 / 停止。
- **WAV 导出**：每个音色旁的「↓ WAV」按钮会用 OfflineAudioContext 离线渲染（含混响尾音）并下载 16-bit 立体声 WAV，循环音色导出 6 秒。

## 结构

```
index.html      页面骨架
css/style.css   样式
js/synth.js     全部音色合成 + 总线 + 离线渲染 / WAV 编码
js/pixel.js     160×90 像素画布动画（PixelMachine）
js/app.js       UI、键盘、循环调度、音序器、导出
```
